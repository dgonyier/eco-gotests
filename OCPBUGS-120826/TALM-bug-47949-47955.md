Description of problem:

```text
TALM emits CguValidationFailure events (events.k8s.io/v1) when a CGU references
non-existent clusters or policies, but the cgu.openshift.io/event-type annotation
(scope) is not set on the event. All other CGU event types (CguCreated, CguStarted,
CguSuccess, CguTimedout) correctly set this annotation to "global", "batch", or
"cluster". CguValidationFailure should set it to "global" since validation failures
apply to the entire CGU.

Other annotations on the CguValidationFailure event ARE correctly populated:
- cgu.openshift.io/missing-clusters and cgu.openshift.io/missing-clusters-count
  (for missing cluster validation failures)
- cgu.openshift.io/missing-policies (for missing policy validation failures)

Only the cgu.openshift.io/event-type annotation is missing.

Observed event dump (missing spoke case):
  CguValidationFailure  scope=-  annotations=[cgu.openshift.io/missing-clusters=non-existent-cluster, cgu.openshift.io/missing-clusters-count=1]

Observed event dump (missing policy case):
  CguValidationFailure  scope=-  annotations=[cgu.openshift.io/missing-policies=non-existent-policy]
```

Steps to Reproduce:

```text
1. Create a CGU in the test namespace referencing a non-existent cluster
   (e.g. spec.clusters: ["non-existent-cluster"]) or a non-existent managed policy
   (e.g. spec.managedPolicies: ["non-existent-policy"])
2. Enable the CGU (set spec.enable: true)
3. Wait for the CGU to reach the validation failure condition
4. List events.k8s.io/v1 events:
   oc get events.v1.events.k8s.io -n <cgu-namespace> \
     --field-selector regarding.kind=ClusterGroupUpgrade -o yaml
5. Inspect the CguValidationFailure event's annotations for cgu.openshift.io/event-type
```

Actual results:

```text
CguValidationFailure event does not have the cgu.openshift.io/event-type annotation.
When listing events, the scope field is empty/missing while all other event types
(CguCreated, CguStarted, CguSuccess, CguTimedout) correctly populate it.
```

Expected results:

```text
CguValidationFailure event should have annotation cgu.openshift.io/event-type set to
"global", consistent with all other CGU event types.
```
